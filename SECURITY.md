# Security policy

MdEditor is a local HTML/CSS/JavaScript interface and a text-based AI skill. The interface has no account system, server, analytics, API keys, or media upload service. Selected files are previewed in the browser; the generated brief contains project choices and file names.

If you discover a security issue, report it privately to the project maintainer through the repository's available private reporting channel. Avoid posting exploit details, credentials, or personal media in a public issue. Include the affected version, steps to reproduce, and the impact you observed.

The latest tagged release is the supported version.
