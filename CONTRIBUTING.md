# Contributing

Pull requests are welcome. Start a discussion before proposing changes to the product direction or to the `/editar` workflow.

- Keep the three editing paths distinct: source-footage editing, motion from scratch, and social recuts.
- Keep one focused question per screen. Make the live preview and final confirmation work on keyboard and touch screens.
- Do not add media, credentials, private footage, user data, or unlicensed fonts, music, logos, or emoji packs.
- Preserve the local-only file behavior unless a future change clearly explains any upload destination and obtains the user's decision.
- State what changed and how it was reviewed. Never claim a render or integration that was not actually run.

The repository owner reviews and merges all changes to the canonical branch.
